# Мої цілі — програма для Android

Та сама програма, що й на claude.ai: щоденний чекліст постів для ріелторства (TikTok, Telegram, Facebook-групи) і трекер цілей життя.
Дані зберігаються на телефоні.

## Встановлення
Відкрий на телефоні **Releases → latest** і завантаж `Cili.apk`, потім відкрий файл і дозволь встановлення.
Нова версія ставиться поверх старої, дані залишаються.

## Як оновити програму
1. Зміни `web/cili.html`.
2. Виконай `python3 web/build_index.py`. Він збирає `app/src/main/assets/index.html`.
3. Завантаж зміни в гілку `main`, і GitHub сам збере новий `Cili.apk` у Releases.
